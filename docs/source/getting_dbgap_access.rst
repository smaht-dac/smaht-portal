    <h3>SMaHT Studies on dbGaP</h3>

The SMaHT datasets were generated as part of the NIH Common Fund consortium initiative, Somatic Mosaicism across Human Tissues (SMaHT). The datasets were provided by the SMaHT Data Analysis Center (DAC) [1UM1DA058230] on behalf of the SMaHT Network.

Protected-access data generated by the SMaHT Network are made available to researchers outside of the SMaHT Network through the NIH database of Genotypes and Phenotypes (`dbGaP <https://www.ncbi.nlm.nih.gov/gap/>`_) following official data releases. The SMaHT datasets are submitted under the following dbGaP studies:

- **SMaHT Benchmarking Data**: `phs004193 <https://dbgap.ncbi.nlm.nih.gov/study/phs004193.v1.p1/#study>`_
- **SMaHT Production Data**: `phs004194 <https://dbgap.ncbi.nlm.nih.gov/study/phs004194.v1.p1/#study>`_

We have released the SMaHT studies on dbGaP, and are in the process of submitting the benchmarking data and the first production data from 25 donors to dbGaP.

    <h3 id="requesting-access">Requesting Access</h3>

Researchers who are not members of the SMaHT Network must submit a Data Access Request (DAR) through the `dbGaP Authorized Access Portal <https://dbgap.ncbi.nlm.nih.gov/aa/landing/>`_ for the relevant SMaHT studies listed above. Upon approval by the NIH Data Access Committee, researchers can access and download the authorized protected-access data through dbGaP.

Integration with the NIH Researcher Auth Service (RAS) is underway to enable researchers with approved dbGaP access to download protected data directly from the SMaHT Data Portal in the future.

To learn which SMaHT data are open-access and which are protected-access, please see our `Data Availability and Access page </docs/access/data-availability-and-access>`_.
